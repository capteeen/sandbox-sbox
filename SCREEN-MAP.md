# Sandbox ($SBOX) — Screen map

1. **/ — Landing**
   - Hero: Cloud boxes for agents.
   - One-liner + Spawn CTA
   - Mini queue preview (3 fake sessions)

2. **/app — Dashboard**
   - $SBOX balance (wallet)
   - Active / queued sandboxes
   - Recent shipped artifacts

3. **/spawn — Spawn**
   - Burn amount
   - Model tier chips (use ai-model-logos)
   - Task prompt
   - Confirm burn → create session

4. **/session/[id] — Session**
   - Stepper: Plan → Execute → Verify → Review → Ship
   - Live log terminal
   - Artifacts panel
   - Approve / Tip buttons

5. **/approve — Approve board**
   - Sessions awaiting review
   - Vote / mark shipped

6. **/cashout — Cash out** (optional v1 stub)
   - Fee → SOL/USDT
