# Sandbox UI — style takeaways

1. **Dark charcoal base** (`#0B0F14`) with one mint CTA — never rainbow chrome.
2. **Narrow left nav** + main stage (Tembo / crypto dash pattern).
3. **Queue cards** with status chips: Queued / Running / Review / Shipped.
4. **Big number hero** for $SBOX balance and burn amount.
5. **Stepper** on session page: Plan → Execute → Verify → Review → Ship.
6. **Mono log terminal** panel; muted text, mint for success lines.
7. **Boxi in empty states** and landing hero — one pet, every emotional beat (LoanMeme Melo rule).
8. **Rounded dark cards**, 12–16px radius, soft borders `#1A2330`.
9. **Model chips** on Spawn use AI logos; keep 3 tiers max.
10. **One primary button** per view (Spawn / Approve / Connect).
11. **Ice blue** (`#7EC8FF`) for links and “running” accents; mint for CTAs.
12. **Mobile**: stack cards; keep stepper horizontal scroll if needed.
