# Sandbox visual references

Research checked on 2026-09-23. These are inspiration for patterns, not assets copied into the app.

| Reference | Useful pattern | Sandbox adaptation |
| --- | --- | --- |
| [AI Agent Workspace by DESH. Group](https://dribbble.com/shots/27639946-AI-Agent-Workspace-Product-UI-UX-Design) | Modular agent cards, soft glow, visible status | Session cards and focused mint/ice status signals |
| [Cloud Infrastructure Platform by Suhayel Ahmed Nasim](https://dribbble.com/shots/27705036-Cloud-Infrastructure-Platform-UI-DevOps-Dashboard) | Dense, scannable operational overview | Dashboard queue, compact metrics, log panel |
| [AetherOps by Ascent Innovate Software](https://dribbble.com/shots/27525143-AetherOps-AI-Workflow-Command-Center-Desktop-Dashboard-UI) | Approval queue alongside activity and system health | Review board and control room navigation |

The local `ui-refs/` folder informed the dashboard, terminal, wallet, and mascot treatments. The app follows the `brand/BRAND.md` palette and avoids showing invented real financial activity: all numbers and actions in this build are labeled as demo data.
