# Sandbox ($SBOX) — Brand lock

## Name
- **Product / coin name:** Sandbox
- **Ticker:** $SBOX
- **Tagline:** Cloud boxes for agents.
- **One-liner:** Burn $SBOX. Spawn a sandbox. Approve the ship.
- **Loop sentence:** Connect wallet → burn/stake $SBOX → agent runs in a cloud box → holders approve → fees to SOL/USDT or burn.

## Positioning
LoanMeme model adapted: **a meme that runs agent sandboxes** (not a lending protocol).
Tembo energy in the UI; Melo energy in the mascot (cute pet face owns every frame).

## Personality
- Soft outside, serious inside
- Pet is chill; the queue is busy
- Never enterprise-corporate; never pure degen spam without the mechanic

## Voice
- Short sentences. Ship / queue / approve / spawn.
- Avoid: “revolutionary AI infrastructure,” Tembo clone claims, fake TVL.
- Do: status labels, burn amounts, session IDs, “nothing ships without the bag.”
